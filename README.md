# Лабораторная работа: Генетический алгоритм (Вариант 15)

## Описание
Реализация базового генетического алгоритма для непрерывной многомерной оптимизации.
Целевая функция: f(x) = sum(i * x_i^2), i=1..d
Ограничения: -10 <= x_i <= 10
Кодирование: вещественное.

## Требования
- Python 3.8+
- NumPy
